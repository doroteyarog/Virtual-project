Desktop Password Manager
A secure, offline desktop password manager built with Python and Tkinter.
Features
•	Master Authentication: Master password protection with PBKDF2 salting.
•	Data Encryption: Passwords encrypted locally at rest using AES.
•	Credential Storage: Store, view, delete and copy account credentials.
•	Local Persistence: Backed by an offline SQLite database.

   ```bash
   git clone [https://github.com/doroteyarog/Virtual-project.git](https://github.com/doroteyarog/Virtual-project.git)
   cd Virtual-project

pip install -r requirements.txt
